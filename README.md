# Widers - منصة إدارة وتسويق محادثات WhatsApp

![Widers](https://via.placeholder.com/800x200/6c5ce7/ffffff?text=Widers)

## نظرة عامة

هذا المشروع عبارة عن صفحة هبوط (Landing Page) لشركة Widers، وهي منصة إدارة وتسويق محادثات WhatsApp عبر API معتمد من Meta. الصفحة تعرض ميزات المنصة بأسلوب عصري ومتجاوب مع مختلف الأجهزة.

## المميزات

- تصميم متجاوب يعمل على جميع أحجام الشاشات
- واجهة عربية بالكامل
- تصميم عصري وحديث مع تأثيرات حركية
- يستخدم HTML5، CSS3، وJavaScript النقي فقط (بدون مكتبات)
- تحميل سريع للصفحة

## الأقسام

1. **الهيدر والتنقل**: قائمة متجاوبة سهلة الاستخدام
2. **البطاقة الرئيسية (Hero)**: عرض رئيسي للمنصة مع وصف موجز
3. **المميزات الرئيسية**: عرض المميزات بترتيب شبكي جذاب
4. **المميزات المتقدمة**: شرح تفصيلي للمميزات مع صور توضيحية
5. **رحلة العميل**: شرح سلس لخطوات الاستخدام
6. **شهادات العملاء**: عرض آراء وتجارب العملاء المسجلة
7. **الخطط والأسعار**: عرض الباقات والأسعار بشكل واضح
8. **الأسئلة الشائعة**: إجابات على الأسئلة المتكررة
9. **مقارنة بالحلول الأخرى**: توضيح فوائد اختيار المنصة
10. **الدعوة الأخيرة**: حث المستخدم على اتخاذ إجراء

## كيفية البدء

1. قم بتنزيل أو استنساخ (Clone) المستودع:

```
git clone https://github.com/yourusername/widers-landing-page.git
```

2. انتقل إلى مجلد المشروع:

```
cd widers-landing-page
```

3. افتح ملف `index.html` في متصفحك المفضل للمعاينة المحلية.

## متطلبات الصور

يجب توفير الصور التالية في مجلد `assets/`:

1. hero-image.webp - صورة أو نموذج لواجهة Widers
2. feature-campaigns.webp - صورة لواجهة إدارة الحملات
3. feature-chatbot.webp - صورة لمنشئ مسارات الدردشة
4. feature-teamchat.webp - صورة لواجهة إدارة محادثات الفريق

يمكنك استخدام صور مؤقتة من:

- https://placeholder.com/
- https://picsum.photos/

## التخصيص

- يمكن تغيير الألوان والخطوط بسهولة من خلال متغيرات CSS في ملف `styles.css`
- يمكن تعديل النصوص ومحتوى الصفحة من ملف `index.html`
